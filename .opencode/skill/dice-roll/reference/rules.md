# 判定规则附录

供 `dice-roll` skill 与地下城主（DM）参照的判定基准表。

## D&D 5e —— 难度等级（DC）

| DC | 难度 | 典型情境 |
|---|---|---|
| 5 | 极易 (Very Easy) | 几乎人人成功 |
| 10 | 易 (Easy) | 普通人稍加留意即可 |
| 15 | 中 (Medium) | 需要一点能力与运气 |
| 20 | 难 (Hard) | 只有行家才常成功 |
| 25 | 很难 (Very Hard) | 高等级角色的挑战 |
| 30 | 近乎不可能 (Nearly Impossible) | 传奇级操作 |

判定：偷骰总值 `总值 ≥ DC` 即成功，否则失败。

**优势 / 劣势**：优势掷两颗 d20 取高，劣势取低；多个来源不叠加（仍只掷两颗）；同时有优势与劣势则相互抵消，掷单颗。

## CoC 7e —— 成功等级

以 d100 结果 `r` 与技能值 `S` 比较（先判大成功/大失败）：

| 等级 | 条件 |
|---|---|
| 大成功 (Critical) | `r == 1` |
| 极难成功 (Extreme) | `r ≤ ⌊S ÷ 5⌋` |
| 困难成功 (Hard) | `r ≤ ⌊S ÷ 2⌋` |
| 常规成功 (Regular) | `r ≤ S` |
| 失败 (Fail) | `r > S` |
| 大失败 (Fumble) | `r == 100`，或 `S < 50` 且 `r ≥ 96` |

> 例：技能值 55 → 大成功 01；极难 ≤ 11；困难 ≤ 27；常规 ≤ 55；失败 56–100（其中 100 为大失败）。

**奖励骰 / 惩罚骰**：在 d100 的十位骰之外，额外多掷一颗十位骰（个位骰共用）。奖励骰取使结果**更低**（更好）的十位骰，惩罚骰取使结果**更高**（更坏）的十位骰。一个奖励骰与一个惩罚骰相互抵消；多个可叠加。

**d100 特例**：十位 `00` + 个位 `0` = **100**；十位 `00` + 个位非 0（如 3）= 个位值（如 3）。奖励骰可借此避开 100。
