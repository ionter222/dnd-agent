# campaign —— 战役与存档

## 何时使用

- 开团前：`new` 建战役，`link` 把玩家角色卡绑进队伍。
- 每段剧情后：`log` 记一笔（标题 + 摘要 + 可选细节 + 游戏内时间）。
- 需要向玩家复述前情：`recap`（给 agent 重装上下文的短回顾）。
- 点名 NPC / 接任务：`npc`、`quest`。
- 一段冒险结束：`rest` 结算长休/短休。
- 升级：`level`（只做等级/生命骰/HP 的通用部分）。

## 先问用户：是否加小说叙事

**首次用 `log` 记录重要剧情前，先问一次用户是否要「结构化存档 + 小说式叙事」；用户答复后不再反复问。**
- 结构化核心（时间/标题/摘要/NPC/任务）**总是写**。
- 小说式 `--details` 是可选项：用户不想多花 token 就不写。
- 用户的偏好用 `novel on|off` 记在战役的 `novel` 字段，之后沿用。

## 命令表

| 命令 | 说明 |
|------|------|
| `new <战役名>` | 新建战役 |
| `list` | 列出所有战役 |
| `status <战役名>` | 战役概览（队伍/进行中任务/最近一条日志） |
| `log <战役名> <标题> <摘要> [--details <细节>] [--time <游戏内时间>] [--tags a,b]` | 追加一条日志 |
| `time <战役名> <文本>` | 设置游戏内时间 |
| `novel <战役名> <on\|off>` | 开启/关闭小说叙事模式 |
| `recap <战役名> [--last N]` | 最近 N 条日志回顾（默认 5） |
| `link <战役名> <角色卡名> [--role pc\|npc]` | 把角色卡绑进队伍 |
| `unlink <战役名> <角色卡名>` | 从队伍移除 |
| `npc <战役名> add <NPC名> [--note <备注>]` | 登记/更新 NPC |
| `quest <战役名> add <任务名> [--detail <细节>]` | 新增任务 |
| `quest <战役名> update <任务名> [--status <状态>] [--detail <细节>]` | 更新任务（状态：进行中/已完成/已失败） |
| `rest <战役名> <long\|short> [--heal N] [--spend N]` | 长休/短休 |
| `level <角色卡名> <职业> [--hp N \| --avg] [--subclass <学派>]` | 升级通用部分 |

所有命令支持 `--json`。顶层 `--campaign-dir` / `--sheet-dir` 可覆盖默认目录（默认 `存档_Saves/` 与 `角色卡_CharacterSheets/`）。

## 铁律

1. **本 skill 不掷骰。** 短休治疗量、升级 HP 由 DM 用 `dice-roll` 掷好后传入（`--heal` / `--hp`）。
2. **法术位与特性手动录入。** `level` 只涨等级/生命骰/HP，法术位、特性由 DM 决定后写进角色卡。
3. **存档进 git。** `存档_Saves/*.json` 是长线成果，随仓库一起保存。
4. **同进程 import `sheet.py`**：HP/法术位/AC 的事实源始终是角色卡。
5. 出错以中文报错并返回退出码 2，绝不静默。

脚本：`scripts/campaign.py`；字段与规则见 `reference/schema.md`。
