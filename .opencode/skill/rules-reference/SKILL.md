# 规则查阅（rules-reference）

把用户放进固定文件夹的规则书 / 模组 / 世界观抽成**本地全文索引**，需要时按关键词把**原文片段**查出来，喂给 DM 做裁定——**不预置任何书**，索引完全本地、**不进 git**。

## 何时用

- DM 要裁定一条**具体规则**（法术/职业特性/战斗细则/状态效果）而不确定原文时。
- 要引用**怪物数据**（AC、HP、攻击、豁免、技能）而记不准时。
- 要查**商品/装备价格**、具体数值表格时。
- 要查**模组**里的房间、NPC、剧情、宝藏（模组长、训练语料少、联网查不到付费内容）。
- 要查**世界观**设定（神系、地理、历史）。

## 铁律（务必遵守）

1. **先问用户要不要建索引**（见下节）——**绝不擅自建**。
2. **不预置任何书**：没有索引就直说，不凭记忆编造规则细节。
3. **查不到就说查不到**——不要用"我记得好像是……"糊弄。
4. **索引不进 git**（`.rule_index/` 已在 `.gitignore`）——规则书有版权。
5. **口径以原文为准**：回答规则问题时，优先引用查到的原文片段。

## 「问用户」行为（首次查阅时必须走）

1. 先跑 `status` 看**有没有索引**。
2. **没有索引**时，问人类：

   > 「需要我建**规则索引**吗？建一次要把 `规则书_Rulebooks/` 等文件夹里的 PDF 抽成文本，**大约几十秒到几分钟**（按书量），**纯本地、不花 token**；建好之后查规则能**引用原文、防幻觉**。不建的话我就凭记忆答（可能记错）。要建吗？」

3. **用户确认后才**跑 `index`（默认只索引 `规则书`；需要全建用 `--all`）。
4. 用户不建 → 就凭记忆答，并声明「未建索引、可能有误」。

## 关键词扩展（重要）

用户/剧情里的**口语**往往不是规则书的**术语**。查询前把口语扩成规则术语再 `query`：

| 口语 | 扩成关键词 |
|---|---|
| 怎么算隐形 | `隐匿 躲藏 潜行` |
| 施法被打断 | `专注 法术 中断` |
| 被推倒 | `倒地 推撞 力量` |
| 黑暗中看不见 | `黑暗视觉 微光 遮蔽` |

`query` 支持多个关键词（空格分隔），按**命中次数**排名返回片段。

## 命令表

| 命令 | 说明 |
|---|---|
| `status` | 查看索引状态（是否存在、来源、书数/块数） |
| `index` | 建索引；默认只建「规则书」，`--source 模组` 指定，`--all` 全建，`--book 关键词` 只建某本 |
| `query 词1 词2 …` | 查询；`--book` 限定书、`--limit N` 限返回条数（默认 5） |
| `books` | 扫描固定文件夹（**含子文件夹**），列出**可索引**的 PDF/txt（未建索引也能用；跳过 `_`/`.` 开头的文件与目录） |

全部命令支持 `--json`（机器可读）。运行方式（在 DNDagent 仓库根）：

```bash
python .opencode/skill/rules-reference/scripts/rules.py query 隐匿 躲藏 --limit 5
python .opencode/skill/rules-reference/scripts/rules.py index --source 规则书
```

## 固定文件夹（约定位置）

| 来源简称 | 文件夹 |
|---|---|
| 规则书 | `规则书_Rulebooks/` |
| 模组 | `模组_Modules/` |
| 世界观 | `世界观_Worldbuilding/` |

索引落在仓库根 `.rule_index/index.json`（可用环境变量 `DND_RULE_INDEX` 覆盖）。字段结构见 `reference/schema.md`。

抽取文本时自动折叠 PDF 字体伪影（如「⼩小」→「小」、无映射部首「⻅见」→「见」），提高检索命中率与引用质量。
