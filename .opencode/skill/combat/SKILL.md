# 战斗 skill（combat）

## 何时使用

- DM 要开一场战斗（遭遇战）：建立战斗、录入先攻、按回合推进。
- 战斗中要查距离、移动、扣血/加血、加条件、击杀、发经验。
- 需要一张坐标地图（防幻觉）：`map` 生成 SVG。

## 核心原则

- **引擎不掷任何骰**（含先攻）：先攻 / 攻击 / 伤害 / 豁免都由 DM 用 dice-roll skill 掷好后喂给本 skill。
- **事实源分离**：HP / 法术位 / 临时 AC / 经验 = 角色卡 JSON；先攻 / 位置 / 条件 / 轮次 / 日志 = 战斗状态 JSON。
- **地图即数据**：`pos` 坐标是事实源；攻击前先 `distance` 查距离，避免"敌人明明够不着却被打到"的幻觉。

## 命令表

| 命令 | 作用 |
|---|---|
| `new <战斗名>` | 新建战斗（grid 30×20，每格 5 尺） |
| `add <战斗名> <单位名> [--side pc\|npc\|enemy] [--pos x,y]` | 加入单位（从角色卡加载校验） |
| `init <战斗名> <单位名> <先攻>` | 录入先攻（DM 掷好后填入） |
| `begin <战斗名>` | 排序开始（未录全先攻会报错） |
| `next <战斗名>` | 推进到下一回合（回绕则轮次 +1） |
| `turn <战斗名>` | 查看当前行动者 |
| `move <战斗名> <单位名> <x> <y> [--force]` | 移动（超速/出界报错，--force 强制） |
| `distance <战斗名> <A> <B>` | 查两点距离（英尺） |
| `damage <战斗名> <单位名> <N>` | 扣血（先扣临时再扣当前，钳 0） |
| `heal <战斗名> <单位名> <N> [--item <物品>]` | 回血（--item 同时扣库存 1） |
| `cond <战斗名> <单位名> add\|remove <条件> [--rounds N]` | 加/移除条件（回合开始倒计时） |
| `kill <战斗名> <单位名> [--xp N] [--share a,b]` | 击杀（移出先攻，经验在参战方平摊） |
| `xp <战斗名> <单位名> <N>` | 手动发经验 |
| `ac <战斗名> <单位名> +\|-\|set\|reset [N]` | 临时 AC |
| `slot <战斗名> <单位名> <环> use\|restore <N>` | 法术位消耗/恢复 |
| `reaction <战斗名> <单位名> used\|reset` | 反应标记 |
| `status <战斗名>` | 概览（轮次/当前/各人 HP·AC·攻击·位置·条件） |
| `map <战斗名> [--out x.svg]` | 生成坐标地图 SVG（给人看） |
| `remove <战斗名> <单位名>` | 移出战斗 |
| `end <战斗名>` | 结束战斗 |

所有命令支持 `--json`。目录用 `--combat-dir` / `DND_COMBAT_DIR`、`--sheet-dir` / `DND_SHEET_DIR` 覆盖。

## 与 dice-roll 联动（引擎不掷骰）

1. 掷先攻：`roll.py "1d20+<敏捷调整>"` → 把结果 `init` 进战斗。
2. 攻击：`roll.py "1d20+<攻击加值>"` → 与目标 AC 比较；命中再掷伤害 `roll.py "<伤害骰>"`。
3. 伤害/豁免：把结果喂给 `damage` / `cond`。

（先 `distance` 确认目标在射程/触及内，再判攻击。）

## HP / 法术位 / AC 落卡

`damage` / `heal` / `ac` / `slot` / `xp` / `kill --xp` 都会**实时写回角色卡 JSON**（同进程 import character-sheet 的 `sheet.py`）。卡里没有的字段/资源会中文报错，不静默。

## 5 条铁律

1. 攻击前先 `distance` 查距离，够不着就别判命中。
2. 任何资源变化（HP/法术位/AC/经验）都必须经本 skill 落卡，别只改叙事。
3. 先攻由 DM 掷后用 `init` 录入；`begin` 前必须全员录全。
4. 条件**不会自动扣血**（中毒/流血伤害由 DM 手动 `damage`）；`cond` 只记状态 + 回合倒计时。
5. 非法输入 / 未知战斗 / 未知单位 / 出界 / 缺卡 / 超速 → 中文报错 + 退出码 2。

脚本：`scripts/combat.py`；规则参考：`reference/rules.md`。
